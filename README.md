### What I work on

- **Embedded firmware** — STM32 (Cortex-M0+/M3/M4), bootloaders, flash layout, UART/RF protocols, low-RAM targets
- **Firmware delivery** — wireless OTA chains with resume, integrity checks, and safe boot recovery
- **Digital design** — VHDL on Xilinx Vivado, including a full AES-256 encryption core
- **AI developer tooling** — multi-agent orchestration, persistent memory for LLMs, agent workflows for embedded work
